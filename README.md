# FOLIO 0.1

Личный книжный дневник для Android. React Native + Expo + TypeScript, настоящая локальная SQLite. Без аккаунта, сервера, рекламы и телеметрии. Библиотека при первом запуске пустая.

## Установка

Скачайте **FOLIO-0.1-Android.zip** в [Releases](https://github.com/elcin31/Book-31/releases), распакуйте и откройте `FOLIO-0.1.apk`. Разрешите установку из выбранного источника. Требуется **Android 7.0 / API 24 или новее, ARM64** (включая Xiaomi Redmi Note 12). APK содержит JavaScript, шрифты и ресурсы: Expo Go, Metro и интернет для запуска не нужны.

Это standalone **release**, подписанный отдельным локальным ключом FOLIO. Ключ не входит в исходники или публичный архив. Для обновлений поверх установленной версии необходимо использовать тот же ключ и повышать Android `versionCode`.

## Возможности

- **Главная:** дата и приветствие, текущие книги и прогресс, быстрый таймер, реальные показатели дня, недельный календарь, годовая цель и последние заметки.
- **Библиотека:** ручное добавление, редактирование всех метаданных, свои обложки, сетка/список, локальный поиск, статусы, сортировка по названию/автору/добавлению, удаление с подтверждением.
- **Каталоги:** необязательный поиск по названию, автору и ISBN. Google Books с независимым fallback на Open Library. Таймауты и понятная ошибка; ручной ввод работает без сети. Загруженные обложки копируются в приватную папку приложения.
- **Книга:** прогресс, даты, оценка, рецензия, заметки и история сессий. Изменения сразу отражаются во всех разделах.
- **Таймер:** старт, пауза, продолжение, сохранение страниц и времени, восстановление после закрытия процесса. Время паузы исключается, сворачивание учитывается. Есть ручные сессии и отдельная запись прогресса без приписывания времени.
- **Дневник:** цитаты, мысли, конспекты; связь с книгой/страницей, избранное, редактирование, удаление, поиск и фильтры.
- **Календарь:** месяцы, дни с обложками или тепловой картой, подробности дня и переход к книгам.
- **Аналитика:** страницы за день/месяц/год, библиотека и статусы, время, средняя сессия, скорость чтения по сессиям с измеренным временем, активные дни; графики дней, месяцев, завершённых книг и распределения времени по книгам.
- **Настройки:** светлая/тёмная/системная тема, годовая цель, ориентир длительности таймера, удержание экрана, вид библиотеки, очистка с двойным подтверждением.

Все основные действия работают офлайн. Интернет используется только по инициативе пользователя для каталога и обложек.

## Дизайн

Тёплый бумажный фон, чернильный зелёный, приглушённое золото, читаемые системные шрифты с serif-заголовками. Светлая и тёмная палитры, компактные карточки, пять нижних вкладок, Android safe-area и нативные переходы. Знакомые принципы книжных продуктов (полки, личный дневник, аналитика привычки) объединены в собственной композиции без копирования экранов. Оригинальный знак открытой книги разработан для FOLIO; SVG-исходники, PNG 1024, adaptive foreground/background, monochrome и splash находятся в `assets/`.

## Разработка и сборка

Рекомендуются Node **22.13+** (или 24), npm, **JDK 17**, Android SDK. Версии JS-зависимостей закреплены в `package-lock.json`.

```sh
npm ci
npm run typecheck
npm test
npx expo install --check
```

Android SDK компоненты:

```sh
sdkmanager 'platforms;android-36' 'build-tools;36.0.0' 'ndk;27.1.12297006' 'cmake;3.22.1'
export ANDROID_HOME=/path/to/android-sdk
export JAVA_HOME=/path/to/jdk-17
npm run build:apk
```

Скрипт генерирует native-проект через Expo prebuild и выполняет `assembleRelease`, проверяет подпись `apksigner`, затем создаёт:

```text
artifacts/FOLIO-0.1-Android.zip
├── FOLIO-0.1.apk
└── README.txt
```

По умолчанию собирается ARM64. Другие ABI задаются `FOLIO_ARCHITECTURES`, например `arm64-v8a,armeabi-v7a`. Включение других ABI увеличивает время и размер сборки.

При первой локальной сборке создаются `.keys/folio-release.jks` и `.keys/signing.env` с приватными правами доступа. **Сохраните их отдельно в безопасном месте**: без того же ключа установить обновление поверх существующей версии нельзя. `.keys`, SDK, toolchains, native build и артефакты исключены из Git. Для своего ключа передайте `FOLIO_KEYSTORE`, `FOLIO_STORE_PASSWORD`, `FOLIO_KEY_PASSWORD`, `FOLIO_KEY_ALIAS` через окружение.

[GitHub Actions](.github/workflows/android.yml) воспроизводит сборку и сохраняет ZIP как artifact на 90 дней. Необязательные repository secrets `FOLIO_KEYSTORE_BASE64`, `FOLIO_STORE_PASSWORD`, `FOLIO_KEY_PASSWORD`, `FOLIO_KEY_ALIAS` обеспечивают один ключ между запусками. Без secrets CI генерирует новый ключ, поэтому такие APK подходят для отдельной установки, но не гарантируют обновление предыдущего APK. Опубликованный локальный APK подписан сохранённым локальным ключом.

`npm start` — разработка; `npx expo export --platform android` — проверка JS/assets Android без Gradle. `android/` генерируется, а его небольшие воспроизводимые изменения находятся в `plugins/withLocalRelease.js`.

## Архитектура и данные

- `src/types.ts`: доменная модель и маршруты.
- `src/schema.ts`: последовательные версионированные миграции `PRAGMA user_version`.
- `src/database.ts`: единый repository, проверки и атомарные транзакции.
- `src/store.tsx`: снимок сохранённых данных для всех экранов, обновление после записи и возврата приложения.
- `src/analytics.ts`, `src/timer.ts`: чистые расчёты без зависимости от UI.
- `src/catalog.ts`: сетевой поиск и локальный кэш обложек.
- `src/ui.tsx`, `src/screens/`: общие компоненты, темы и экраны.

Схема: `Books`, `ReadingAttempts`, `ReadingSessions`, `Notes`, `ReadingGoals`, `AppSettings`. Включены внешние ключи, каскадное удаление, индексы, WAL и ограничения значений. Сессии отделены от актуальной страницы книги. Активный таймер хранит начальную страницу, накопленное время и timestamp текущего отрезка; каждый переход сразу сохраняется в SQLite. Одновременное изменение прогресса активной книги запрещено до сохранения/отмены таймера. При ошибке открытия базы отображается ошибка с повтором, вместо подмены данных пустой библиотекой.

## Проверка

`npm test` выполняет unit/integration тесты: настоящая SQLite-схема и production repository через адаптер Node SQLite, CRUD, повторное открытие файла, атомарность, ограничения, каскады, таймер/пауза/восстановление, двойное сохранение, аналитика нулевых значений и каталоги с сетевыми ошибками. Данные тестов изолированы и не включаются в APK.

Для дополнительной проверки общей UI-логики в Chromium:

```sh
npx expo export --platform web
node scripts/serve-preview.mjs
# В другом терминале (укажите CHROMIUM_PATH при необходимости):
node scripts/qa-browser.mjs
```

Это локальная QA-версия с SQLite WASM, **не Android-эмулятор и не веб-продукт**. Expo SQLite в новых Chromium иногда требует на первом открытии нажать «Повторить» из-за короткого синхронного worker timeout; Android использует другой, нативный SQLite bridge. Достоверные результаты конкретной сборки приведены в [QA.md](QA.md).

## Ограничения 0.1

- Нет EPUB-читалки, синхронизации, импорта/экспорта резервной копии или уведомления таймера в системной шторке.
- Удаление приложения/очистка данных удаляет библиотеку. Android cloud backup отключён, чтобы данные оставались локальными.
- Сессия через полночь целиком относится ко дню начала. Таймер основан на часах устройства; ручная смена системного времени может повлиять на результат.
- История повторных попыток хранится, но отдельного интерфейса управления перечитываниями пока нет.
- Удалённые/заменённые обложки могут оставаться в приватном кэше до удаления данных приложения.
- Доступность и качество метаданных каталогов не гарантируются. При ошибке загрузки обложки её можно убрать и сохранить книгу вручную.
- Релиз 0.1 содержит ARM64; 32-битные и x86-устройства не поддерживаются этим APK.
