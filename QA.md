## Автоматические проверки

TypeScript и **12 тестов проходят** локально и в CI. Repository проверяется не поддельными массивами: production SQL выполняется через совместимый мост в настоящем SQLite на диске.

Покрыты CRUD, переоткрытие базы, сохранение настроек и цели, внешние ключи, каскады, атомарность, неверный прогресс, восстановление/пауза таймера, запрет повторного сохранения, заметки и избранное, нулевые знаменатели аналитики, ошибки Google Books и fallback Open Library.

Реальный сетевой вызов `searchCatalog('The Hobbit','title')` вернул **24 книги из Open Library**. Google Books в среде проверки отвечает 429; независимый fallback работает.

## Общий интерфейс

Через React Native Web + Chromium выполнены добавление книги, изменение страницы, создание/редактирование заметки, запуск/пауза/продолжение таймера, восстановление после закрытия страницы, сохранение сессии, повторное открытие библиотеки, все вкладки, две темы, календарь и переключение месяцев. После отключения сети основные действия продолжили работать.

В ходе проверки исправлены конфликт завершения книги с активным таймером, повторное сохранение сессии и асинхронное освобождение wake lock. Тестовые книги существуют только в изолированных тестовых базах/браузере; APK поставляется с пустой библиотекой.

Веб-проверка **не заменяет Android**: экспериментальный Expo SQLite WASM bridge в Chromium выдаёт worker startup/reload ошибки (`Sync operation timeout`, `[object Object]`). Скрипт сохраняет их и возвращает ошибку, даже когда сами действия завершились. Эти ошибки относятся к web bridge; Android APK использует нативный SQLite. Web не является поддерживаемой платформой релиза.
